Install in three steps

Evopix is installed directly from this site, so Android asks you to allow it once.

  1. Download the APK

    Tap Download APK above. If your browser warns about the file type, choose Download anyway.

  2. Allow this install

    Open the file. When asked, go to Settings → Install unknown apps and allow your browser or Files app.

  3. Install and open

    Go back, tap Install, then Open. Your projects are saved on the start screen.

Questions

Is Evopix free?

Yes. Download it and use every tool without an account.

Why isn't it on the Play Store?

Evopix is distributed directly from evopix.in for now. Only download it from this site so you always get the official file.

Can I use it on my PC?

Yes. Install the APK in an Android emulator such as BlueStacks. Mouse-wheel zoom and keyboard shortcuts work there.

What formats can I export?

Save finished images as PNG or JPG at the pixel size you choose, or keep the project to continue editing later.

How do I update?

Download the newest APK from this page and install it over the old one. Your saved projects stay where they are.
